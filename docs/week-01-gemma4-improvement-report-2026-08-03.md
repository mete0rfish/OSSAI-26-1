# Week 1 Gemma 4 지시문(prompt) 비교 결과

이 보고서는 같은 Gemma 4 모델에 기준 지시문과 개선 지시문을 적용한 결과를 학습하기 위한
자료다. 저장된 실제 응답을 현재 이미지 전용 고정 규칙 채점기
`aihub-vqa-deterministic-v2`로 다시 계산했다. 새 API 호출은 하지 않았다.

## 학습 목표

- 모델과 데이터를 고정하고 지시문만 바꾸는 비교 방법을 이해한다.
- 출력 구조, 정답, 근거를 서로 다른 지표로 확인한다.
- 평균 점수가 올라도 새 실패나 API 오류가 있으면 결론을 보류해야 하는 이유를 이해한다.

## 비교 조건

| 구분 | 기준 지시문 | 개선 지시문 |
| --- | --- | --- |
| 모델 | Gemma 4 31B | Gemma 4 31B |
| 데이터 | 같은 AIHub 질문 40건 | 같은 AIHub 질문 40건 |
| 모델 입력 | 질문과 페이지 JPEG | 질문과 페이지 JPEG |
| 출력 형식 | 같은 JSON 구조(schema) | 같은 JSON 구조 |
| 채점 | 같은 이미지 전용 고정 규칙 채점기 | 같은 이미지 전용 고정 규칙 채점기 |
| 바꾼 항목 | 없음 | 지시문만 변경 |

PDF 추출 문장은 VLM 입력과 채점에 포함하지 않았다. 질문과 페이지 JPEG만으로 만든 응답을
같은 규칙으로 비교한다.

## 지시문에서 바꾼 점

| 발견한 문제 | 개선한 지시 |
| --- | --- |
| 질문의 연도와 항목을 답에 다시 써서 숫자 비교가 실패함 | 숫자 질문에는 값과 단위만 작성 |
| 표의 인접한 값을 선택함 | 대상·연도·기간·단위를 구분하고 행과 열을 다시 확인 |
| 근거를 요약하거나 말줄임표를 사용함 | 답을 직접 포함하는 연속된 문구만 인용 |
| JSON만 반환하라고 하면서 코드 블록으로 감싼 JSON 예시를 제공함 | Markdown 코드 블록 표시(fence)가 없는 JSON 객체 예시 사용 |

## 결과

| 지표 | 기준 | 개선 | 변화 |
| --- | ---: | ---: | ---: |
| 전체 성공(`task_success`) | 9/40, 22.5% | 28/39, 71.8% | +49.3%p |
| 숫자 일치(`numeric_match`) | 40.0% | 84.6% | +44.6%p |
| 순수 JSON(`json_object_only`) | 0.0% | 28.2% | +28.2%p |
| 출력 형식 통과(`schema_validity`) | 92.5% | 89.7% | -2.8%p |

- 기준: 성공 9건, 실패 31건
- 개선: 성공 28건, 실패 11건, API 오류로 비교하지 못한 사례 1건
- 사례 변화: 새 성공 20건, 새 실패 1건, 변화 없음 18건, 비교 불가 1건
- 개선 지시문의 출력 토큰(token)은 기준보다 44.3% 적었다.

짧은 답 규칙은 정답과 숫자 일치를 크게 높였다. 반면 깨진 JSON과 허용하지 않은 필드(field)가
늘어 출력 형식 통과율은 낮아졌다. 한 지표의 개선이 전체 품질 개선을 보장하지 않는다는
뜻이다.

## 대표 실패 사례

| 사례 | 관찰 | 해석 |
| --- | --- | --- |
| `r01` | 기준 답에 질문의 연도와 설명이 함께 들어감 | 짧은 값 규칙으로 새 성공 |
| `r22` | 표의 인접 값을 선택함 | 행·열 확인이 더 필요함 |
| `r24` | API가 HTTP 500을 반환함 | 모델 오답이 아니라 비교 불가 |
| `r31` | 문서에 없는 기간의 숫자를 추측하고 JSON도 깨짐 | 답변 보류와 구조 검사가 모두 필요함 |
| `p06` | 허용하지 않은 필드(field)를 반환함 | 출력 형식 통과 여부를 별도로 확인해야 함 |

구문 분석기(parser)가 마지막 JSON만 골라내거나 채점기가 긴 답에서 기대 숫자만 추출하도록
완화하면 출력 형식 문제를 숨기게 된다. 지시문 실험에서는 모델 출력과 채점 규칙을 동시에 바꾸지
않는다.

## 결과 해석

자동 판정은 판단 보류(`inconclusive`)다. 성공률은 크게 올랐지만 새 실패가 1건 생겼고 API 오류로
비교하지 못한 사례도 1건 있기 때문이다. 이 결과는 개선 가능성을 보여 주지만 지시문을
자동 채택할 충분한 근거는 아니다.

다음 비교에서는 다른 조건을 고정한 채 다음 두 항목을 확인한다.

1. 답할 근거가 없으면 숫자를 추측하지 않고 답변을 보류하는가?
2. 정해진 필드만 사용한 유효한 JSON 객체 하나를 반환하는가?

## 학습자 확인 항목

- 두 실행에서 모델, 질문, 이미지, 출력 형식과 채점 기준이 같은가?
- API 오류를 모델 실패와 분리했는가?
- 평균 점수뿐 아니라 새 성공과 새 실패 사례를 함께 확인했는가?
- 진단 지표 하나를 전체 성공으로 해석하지 않았는가?
